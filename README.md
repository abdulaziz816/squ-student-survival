# SQU Student Survival

A Pygame dodger game built for COMP3600 (Intelligent Systems) at Sultan Qaboos University.

## How to Play

Avoid the SQU-themed hazards spawning from random directions. You have 3 lives — survive as long as you can!

## Features

- Character selection screen with 3 playable characters
- SQU-themed hazards spawning from randomised edges with vector-based trajectories
- Probability-driven difficulty scaling that ramps up over time
- Lives system and live score HUD

## Requirements

```
pip install pygame
```

## Run

```
python part1_dodger.py
```
